Les documents dans le fichier Legal:

Tous les documents n'ont pas besoin d'être signés par l'établissement. Il faut distinguer les documents contractuels de ceux qui sont des politiques internes/publiques.

| Document                                 | Signature de l'établissement ? | Comment le gérer                                                             |
| ---------------------------------------- | ------------------------------ | ---------------------------------------------------------------------------- |
| **Contrat SaaS**                         | ✅ Oui                          | Signé par les deux parties                                                   |
| **DPA / Accord de sous-traitance**       | ✅ Oui                          | Signé par les deux parties, idéalement annexé au contrat                     |
| **Politique de confidentialité**         | ❌ Généralement non             | Publiée sur la plateforme/site et communiquée aux personnes concernées       |
| **CGU**                                  | ⚠️ Pas nécessairement          | Acceptation électronique par l'utilisateur ou l'établissement selon le cas   |
| **Politique de sécurité**                | ❌ Non                          | Document interne du Prestataire, éventuellement communiqué à l'établissement |
| **Procédure de suppression des données** | ❌ Non                          | Procédure interne, référencée dans le contrat/DPA                            |
