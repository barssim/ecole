## 2. Données collectées

Selon les fonctionnalités utilisées, la plateforme peut traiter :

* nom et prénom ;
* date de naissance ;
* classe ;
* identifiant scolaire ;
* coordonnées ;
* absences ;
* retards ;
* notes ;
* résultats ;
* informations relatives aux parents/tuteurs ;
* informations relatives aux enseignants ;
* données techniques de connexion ;
* journaux de sécurité.

## 3. Finalités

Les données peuvent être traitées afin de :

* gérer les élèves ;
* gérer les classes ;
* gérer les enseignants ;
* suivre les absences ;
* gérer les notes ;
* générer les bulletins ;
* communiquer avec les parents ;
* assurer le fonctionnement technique ;
* assurer la sécurité ;
* effectuer des sauvegardes ;
* fournir le support.

## 4. Minimisation

La plateforme est conçue pour limiter la collecte aux informations nécessaires aux fonctionnalités activées.

L'Établissement ne doit pas introduire de données qui ne sont pas nécessaires à ses finalités.

## 5. Destinataires

Les données peuvent être accessibles aux :

* utilisateurs autorisés de l'établissement ;
* administrateurs techniques du Prestataire lorsque nécessaire ;
* prestataires techniques autorisés ;
* autorités compétentes lorsque la loi l'exige.
